# Clutch: test builds

Thanks for testing Clutch, a streaming, recording and clipping studio.

The source code isn't here. This repo only holds test builds and your feedback.

## Install

Grab the newest build from **[Releases](../../releases)**, then follow the **[Testing guide](TESTING.md)**:

- **Windows 10/11:** download `Clutch-<version>-x64.msi` and run it. Windows SmartScreen may warn because the build isn't signed yet: click *More info → Run anyway*.
- **Linux (x86_64):** download `Clutch-<version>-x86_64.AppImage`, then `chmod +x Clutch-*.AppImage` and run it.

## Report a bug or suggest something

Open an **[issue](../../issues/new/choose)** and pick *Bug report* or *Suggestion*.
One issue per problem or idea, please. Screenshots, short screen recordings and log files help a lot.

Before reporting, check the newest release: your issue may already be fixed.
